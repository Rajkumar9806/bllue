================================================================================
API ENDPOINTS ADDED
================================================================================

1. GET /api/recommendations/smart
   Purpose: Get smart personalized date ideas
   Auth: Required (JWT token)
   Query Parameters:
   - mood (optional): adventurous|romantic|low_key|spontaneous|foodie|creative
   - lat (optional): Latitude for weather lookup
   - lon (optional): Longitude for weather lookup
   - count (optional, default 5): Number of ideas
   
   Response: { "ideas": [...], "count": 5 }

2. GET /api/recommendations/preferences
   Purpose: Get user's computed preference profile
   Auth: Required (JWT token)
   Query Parameters: None
   
   Response: {
     "category_scores": {...},
     "budget_preference": {...},
     "location_preference": {...},
     "top_tags": [...],
     "avoided_tags": [...],
     "total_interactions": N,
     "acceptance_rate": 0.0-1.0,
     "confidence": "low|medium|high",
     "personality_evolution": "string"
   }

3. GET /api/recommendations/mood-options
   Purpose: Get available mood options
   Auth: Not required (can be public)
   Query Parameters: None
   
   Response: {
     "moods": {
       "adventurous": "...",
       "romantic": "...",
       ...
     }
   }

4. GET /api/recommendations/partner-compatibility
   Purpose: Get couple compatibility analysis
   Auth: Required (JWT token)
   Query Parameters:
   - partner_id (optional): UUID of partner (auto-detects if not provided)
   
   Response: {
     "compatibility_score": 0-100,
     "shared_categories": [...],
     "compromise_categories": [...],
     "conflict_categories": [...],
     "ideal_budget": "low|medium|high",
     "ideal_location": "indoor|outdoor|both",
     "recommended_tags": [...],
     "avoid_tags": [...]
   }

================================================================================
KEY METRICS & FORMULAS
================================================================================

Category Affinity Score:
  score = accepted_count / (accepted_count + rejected_count)
  Range: 0.0 (never accepted) to 1.0 (always accepted)
  
Confidence Levels:
  < 5 interactions: "low"
  5-15 interactions: "medium"
  15+ interactions: "high"

Acceptance Rate:
  rate = accepted_ideas / total_interactions
  Range: 0.0 to 1.0

Compatibility Score:
  base = 50
  + min(shared_categories × 10, 30)
  + 10 if (rate1 + rate2 > 1.2)
  - conflict_categories × 5
  Final range: 0-100
